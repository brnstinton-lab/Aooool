# Project Guidelines & Rules

## Core Workflow Principle
- **Один промпт — одна законченная функция**: Каждый запрос должен реализовывать ровно одну завершённую, протестированную и изолированную функцию без неанонсированных побочных изменений или незавершённых шагов.

## Architecture
- Django + Templates + Alpine.js + Tailwind CSS.
- Существующая архитектура и работающий код сохраняются без избыточных переписываний.
- Модели и структура разрабатываются строго по требованиям и этапам роадмапа.
