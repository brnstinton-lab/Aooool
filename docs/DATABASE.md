# База данных AUL

## Назначение
База данных предназначена для хранения информации приложения AUL. Каждая сущность хранится в отдельной таблице. Все данные должны иметь уникальный идентификатор (ID).

---

## 1. Таблицы базы данных

### 📢 Таблица: Официальные объявления (`Announcement`)
Хранит официальные объявления для жителей населённого пункта (отключения света, воды, ремонт дорог, события акимата).

> **ВАЖНОЕ ПРАВИЛО:** Слово `Notification` зарезервировано для будущей системы Push-уведомлений (`PushNotification`). Модель официальных объявлений называется **`Announcement`**.

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | BigAutoField | Уникальный ID |
| `title` | CharField(255) | Заголовок |
| `description` | TextField | Описание |
| `category` | TextChoices | Категория (`ELECTRICITY`, `WATER`, `ROADS`, `EMERGENCY`, `IMPORTANT`, `EVENT`) |
| `village` | CharField(100) | Населённый пункт (текстовое поле, спроектировано для будущей связи с `Village`) |
| `publish_date` | DateTimeField | Дата публикации |
| `expire_date` | DateTimeField | Дата окончания действия (null/blank) |
| `is_important` | BooleanField | Флаг "Важное" |
| `is_pinned` | BooleanField | Флаг "Закреплено" |
| `image` | ImageField | Изображение (`announcements/`) |
| `status` | TextChoices | Статус (`ACTIVE`, `ARCHIVED`) |
| `created_at` | DateTimeField | Дата создания (автозаполнение) |
| `updated_at` | DateTimeField | Дата обновления (автозаполнение) |

## 2. Связи между таблицами

```
Организация ────► Оповещения
Объявление  ────► Фотографии

Контакты (самостоятельная таблица)
Поездки   (самостоятельная таблица)
```

---

## 3. Автоматические правила

- **Оповещения:** После окончания времени отключения статус автоматически меняется на **Архив**.
- **Поездки:** После времени отправления статус автоматически меняется на **Архив**.
- **Объявления:** Через 30 дней предлагается продлить публикацию. Если пользователь не продлевает — **Архив**.
