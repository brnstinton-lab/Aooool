# 🏛️ Архитектура проекта AUL

## 1. Общий архитектурный подход

Проект **AUL** построен по схеме **классического монолита** на Django с серверным рендерингом страниц (`Django Templates`) и лёгкой клиентской интерактивностью на `Alpine.js` и `HTMX`.

Данный выбор сделан для обеспечения:
- **Максимальной простоты поддержки** человеком без глубокого опыта в JavaScript/React;
- **Высокой скорости разработки** (всё в рамках одного Django-проекта);
- **Минимальных требований к ресурсам** смартфона (быстрая загрузка без лишних JS-бандлов);
- **Простоты превращения в PWA** (Progressive Web App).

---

## 2. Технологический стек

- **Backend & Рендеринг:** Python 3.10+ / Django 5.x
- **Шаблонизатор:** Django Template Engine (HTML5)
- **Клиентская интерактивность:**
  - **Alpine.js** (микро-состояния: модальные окна, фильтры, раскрывающиеся меню, переключатели вкладок)
  - **HTMX** (подгрузка данных и отправка форм без полной перезагрузки страницы)
- **Стилизация:** Tailwind CSS (адаптивная мобильная верстка)
- **База данных:** SQLite3 (разработка) / PostgreSQL (продакшн)
- **Медиа и Статика:** Django Static & Media Files

## 3. Структура монолитного приложения

```text
backend/
├── manage.py                   # Главная утилита управления Django
├── aul_project/                # Главный модуль конфигурации
│   ├── settings.py             # Настройки (TEMPLATES, STATIC, TIME_ZONE, APPS)
│   ├── urls.py                 # Главный роутер маршрутов
│   └── wsgi.py / asgi.py       # Точки входа для серверов
├── apps/                       # Изолированные Django-приложения
│   ├── notifications/          # Приложение «Оповещения»
│   ├── trips/                  # Приложение «Поездки»
│   ├── ads/                    # Приложение «Объявления»
│   └── directory/              # Приложение «Справочник»
├── templates/                  # Главные HTML-шаблоны
│   ├── base.html               # Базовый каркас (Alpine.js, HTMX, Tailwind)
│   ├── notifications/          # Шаблоны оповещений
│   ├── trips/                  # Шаблоны поездок
│   ├── ads/                    # Шаблоны объявлений
│   └── directory/              # Шаблоны справочника
├── static/                     # Статические файлы (CSS, JS, иконки)
└── media/                      # Загружаемые пользователями файлы (фотографии)
```

## 4. Взаимодействие компонентов (Request-Response Flow)

1. **Запрос пользователя:** Браузер отправляет GET/POST запрос на сервер Django.
2. **Маршрутизация (urls.py):** Запрос передается в представление (view) соответствующего приложения.
3. **Обработка (views.py):** Представление запрашивает данные из моделей (ORM) и формирует контекст.
4. **Рендеринг (Django Templates):** Сервер генерирует готовый HTML-код с помощью шаблонов.
5. **Динамика (Alpine.js & HTMX):**
   - **Alpine.js** обрабатывает быстрые локальные действия на клиенте (открытие формы, скрыть/показать блок).
   - **HTMX** отправляет AJAX-запросы на сервер и обновляет только нужный фрагмент страницы без перезагрузки.
