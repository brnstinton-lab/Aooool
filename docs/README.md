# Документация проекта AUL

Добро пожаловать в раздел документации веб-приложения **AUL**.

## Структура файлов документации

- `FOUNDATION.md` — Видение, Миссия и Принципы проекта
- `RESEARCH.md` — Исследования, Пользователи и Анализ проблем WhatsApp-чатов
- `PRODUCT.md` — Описание продукта AUL: MVP, Модули, Сценарии, Правила, Роли и Жизненный цикл
- `RULES.md` — Правила публикации: Поля, Валидация, Сроки действия, Удаление и Ограничения
- `DESIGN.md` — Концепция дизайна, Material Design 3, Дизайн-код, Палитра и Экраны
- `ADMIN.md` — Панель администратора: Управление, Дашборд, Разделы и Логирование
- `DATABASE.md` — Схема базы данных, таблицы, связи и правила (Django ORM)
- `DEVELOPMENT_PLAN.md` — План разработки (13 этапов MVP, релизы v1.1 и v2.0)
- `DICTIONARY.md` — Словарь данных, статусы, категории и форматы
- `REQUIREMENTS.md` — Требования к проекту и функционал
- `ARCHITECTURE.md` — Архитектура приложения и модули
- `API.md` — Спецификация API эндпоинтов (REST API)
