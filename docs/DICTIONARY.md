# 📖 Словарь данных AUL

## Назначение
На этой странице описаны допустимые значения и стандарты, используемые в базе данных AUL. Использование значений, не указанных в словаре, не допускается.

---

## 1. Перечисления и Статусы

### Статусы публикаций
Используются для Оповещений, Поездок и Объявлений:
- **Активно** — Публикация отображается пользователям.
- **Архив** — Публикация скрыта и находится в архиве.

### Категории поиска
- ⚡ Оповещения
- 🚗 Поездки
- 🛒 Объявления
- 📞 Контакты

### Категории контактов
- 🚨 Экстренные службы
- 🏛 Государственные организации
- 🏫 Образование
- 🏥 Здравоохранение
- 🛒 Магазины
- 🚕 Такси

### Источники оповещений
- РЭС
- Акимат
- Водоснабжение
- Газовая служба
- Администрация AUL

### Причины отключения
- Плановые работы
- Аварийное отключение
- Ремонт оборудования
- Подключение новых потребителей
- Техническое обслуживание
- Другое

### Категории объявлений
- Продажа
- Покупка
- Отдам бесплатно
- Ищу
- Аренда

---

## 2. Сроки действия и Ограничения

| Тип публикации | Срок действия / Правило |
| --- | --- |
| **Оповещение** | До окончания времени отключения (авто-архив) |
| **Поездка** | До времени отправления (авто-архив) |
| **Объявление** | 30 дней (с предложением продления перед архивацией) |
| **Макс. фото в объявлении** | До 5 фотографий |

---

## 3. Форматы данных

- **Телефон:** Международный формат (например, `+7 777 123 45 67`).
- **Дата:** `ДД.ММ.ГГГГ` (например, `25.07.2026`).
- **Время:** 24-часовой формат `ЧЧ:ММ` (например, `09:00`, `18:30`).
- **Логические значения:** Да (Истина) / Нет (Ложь).

---

## 4. Принципы словаря данных

1. Все значения должны использоваться одинаково во всех модулях.
2. Не допускается создание новых статусов или категорий без обновления словаря данных.
3. При появлении нового модуля его значения сначала добавляются в словарь, а затем используются в коде.
