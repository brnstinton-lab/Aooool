# 🛠 Панель администратора AUL

## Назначение
Панель администратора предназначена для управления всеми данными приложения AUL. Через нее администратор может создавать, редактировать, публиковать и удалять информацию без изменения программного кода.

---

## 1. Основные требования
- Доступ через веб-браузер только для авторизованных пользователей.
- Простой и понятный интерфейс, оптимизированный под ПК и мобильные устройства.
- Сохранение изменений мгновенно после подтверждения.

---

## 2. Главная страница (Дашборд)
Отображает оперативные метрики и последние действия системы:

```
--------------------------------------------------
                     AUL Admin
--------------------------------------------------
Сегодня:
⚡ Активные оповещения        2
🚗 Активные поездки          4
🛒 Активные объявления      18
📞 Контактов                46
--------------------------------------------------
Последние действия:
• Создано оповещение (РЭС)
• Добавлена поездка
• Изменён контакт организации
--------------------------------------------------
```

---

## 3. Боковое меню и Структура

### Рабочие разделы
- 🏠 **Главная** — Дашборд со статистикой.
- ⚡ **Оповещения** — Создание, изменение, удаление, досрочное завершение, архив отключений.
- 🚗 **Поездки** — Просмотр, удаление, поиск, автоматический архив после отправления.
- 🛒 **Объявления** — Просмотр, фотогалерея, удаление, поиск, архив по истечению 30 дней.
- 📞 **Контакты** — Ведение официального справочника аула (название, категория, телефон, адрес, часы работы, описание).

### Управление системой
- 🏛 **Организации** — Список официальных структур (РЭС, Акимат, Школа, Больница, Библиотека) с перспективой разграничения прав.
- ⚙ **Настройки** — Название аула, логотип, описание, управление Push-уведомлениями.
- 📜 **История изменений** — Журнал действий (логирование времени, типа действия и автора изменений).

---

## 4. Поиск, Архив и Права доступа

### Поиск
Единый сквозной поиск во всех разделах админ-панели по названию, населенному пункту, телефону, категории и дате.

### Архив
Каждый модуль снабжен архивом с возможностью просмотра, полного удаления или восстановления записей.

### Права доступа
- **Версия 1.0:** Единственная роль главного администратора с полными правами.
- **Будущие версии:** Разграничение ролей (Администратор, Оператор РЭС, Представитель организации, Модератор).

---

## 5. Принципы админ-панели
1. Все действия выполняются через браузер.
2. Любая запись находится за несколько секунд.
3. Интерфейс проще офисных программ.
4. Мгновенное сохранение подтвержденных данных.
5. Четкое разделение на «Управление системой» и «Рабочие разделы».
