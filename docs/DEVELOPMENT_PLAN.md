# План разработки AUL

## Назначение
Описание последовательности разработки приложения AUL. Каждый этап должен завершаться полностью рабочим функционалом.

---

## 🛠 Этапы разработки MVP (Версия 1.0)

### Этап 1. Подготовка проекта
**Цель:** Создать основу проекта.
- Создать репозиторий Git.
- Создать проект Django.
- Настроить виртуальное окружение.
- Подключить PostgreSQL.
- Настроить Django Admin.
- Создать базовую структуру проекта.
- Настроить хранение изображений.
- Создать главную страницу.
**Результат:** ✅ Запускается базовый каркас приложения AUL.

### Этап 2. База данных
**Цель:** Создать модели данных.
- Создать модели: Оповещения, Поездки, Объявления, Фотографии объявлений, Контакты, Организации.
- Настроить связи между моделями и миграции.
**Результат:** ✅ Все модели отображаются в Django Admin.

### Этап 3. Панель администратора
**Цель:** Настроить удобную работу администратора.
- Отображение таблиц, поиск, фильтры, сортировка и редактирование.
**Результат:** ✅ Управление всеми данными через браузер.

### Этап 4. Модуль «Оповещения»
**Цель:** Реализовать ключевой модуль.
- Список, просмотр, создание оповещений, авто-архивация.
**Результат:** ✅ Пользователи получают информацию об отключениях.

### Этап 5. Модуль «Поездки»
- Создание поездки, просмотр, поиск, архив.
**Результат:** ✅ Пользователи публикуют поездки.

### Этап 6. Модуль «Объявления»
- Создание объявления (до 5 фото), просмотр, поиск, архив.
**Результат:** ✅ Доска объявлений работает.

### Этап 7. Модуль «Контакты»
- Категории, поиск, карточка организации, кнопка «Позвонить».
**Результат:** ✅ Доступ к справочнику организаций.

### Этап 8. Единый Поиск
- Сквозной поиск по оповещениям, поездкам, объявлениям и контактам.
**Результат:** ✅ Поиск по всему приложению.

### Этап 9. Интерфейс
- Material Design 3, адаптивность, нижняя панель, главная страница, карточки.
**Результат:** ✅ Интерфейс соответствует дизайну.

### Этап 10. PWA
- Установка на телефон, иконка, Splash Screen, автономность.
**Результат:** ✅ Установка на Android как приложение.

### Этап 11. Push-уведомления
- Подписка пользователя, отправка уведомлений об отключениях.
**Результат:** ✅ Мгновенные уведомления о важных событиях.

### Этап 12. Тестирование
- Проверка создания публикаций, поиска, архивации, загрузки фото, работы на мобильных устройствах.
**Результат:** ✅ Первая версия готова к выпуску.

### Этап 13. Первый запуск
- Заполнение справочника, первые оповещения, финальная проверка.
**Результат:** ✅ Запуск приложения для жителей посёлка.
